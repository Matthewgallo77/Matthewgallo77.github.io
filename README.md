# ScrollDoctor website

Public product, privacy, and support website for ScrollDoctor.

## Structure

- `/` — concise product overview
- `/privacy/` — App Store privacy policy
- `/support/` — support guidance and contact route
- `/assets/` — shared brand assets and styles

The site is intentionally static: there are no dependencies, build step,
analytics, cookies, or client-side scripts. GitHub Pages publishes the files
directly from the default branch.
